# kotlin-lotto

## Step1 - String Addition Calculator

### Implementation details
- When a string is provided with comma ( ,) or colon ( :) as delimiters, return the sum of the numbers split by these delimiters.
- In addition to the default delimiters ( ,and :), a custom delimiter can be specified. A custom limiter is defined between //and \n
- If the input contains non-numeric values or negative numbers , throw a RuntimeException.

- StringAddCalculator will have an add function and a parsing function
