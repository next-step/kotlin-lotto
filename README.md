# kotlin-lotto

## 기능목록

### 1. 구입금액을 입력받는다
로또 1장 : 1000원
- 시스템 입력을 통해 구입금액을 입력받는다.
  - 입력 : 구입금액을 입력해 주세요.
- 입력한 구입금액에 맞는 로또 갯수를 출력한다
  - OO개를 구매했습니다.
- 구입금액을 음수로 입력한 경우 오류 메시지를 출력 후 프로그램이 실행되지 않는다.
  - 구매 금액은 0원보다 커야 합니다. 입력한 구매금액: ???원

### 2. 수동으로 구매할 로또 수를 입력 받는다.
- 시스템 입력을 통해 수동으로 구매할 로또 수를 입력받는다.
  - 입력 : 수동으로 구매할 로또 수를 입력해 주세요.
- 구입금액으로 입력한 로또 구매 갯수보다 클 경우 예외를 발생시킨다.
  - 수동으로 구매할 로또 수는 로또 구매 갯수보다 작아야합니다. 로또 구매 갯수: ???개

### 3. 수동으로 구매할 로또 번호를 입력받는다.
- 시스템 입력을 통해 수동으로 구매할 로또 번호를 입력받는다.
  - 입력 : 수동으로 구매할 번호를 입력해 주세요.
- 입력한 로또 수가 6개가 아닌 경우 예외를 발생시킨다.
  - 로또번호는 중복 없는 6자리 숫자여야합니다.
- 입력한 로또 번호 중 1~45 사이가 아닌게 존재하는 경우 예외를 발생시킨다.
  - 로또 번호는 1~45 사이여야합니다.

### 4. 구입금액에 만큼 로또 번호 자동+수동으로 생성한다
- 1 ~ 45 사이의 중복되지 않는 숫자 6개를 랜덤으로 뽑아 로또 번호를 생성한다.
- 수동, 자동 로또 수를 응답한다.
  - 출력 : 수동으로 3장, 자동으로 11개를 구매했습니다.
- 생성된 로또 번호를 출력한다.
  - [1, 2, 3, 4, 5, 6]

### 5. 지난주 당첨번호를 입력받는다
- 시스템 입력을 통해 지난주 당첨번호 6개를 입력받는다.
  - 입력 : 지난 주 당첨번호를 입력해 주세요.
- 입력한 로또 수가 6개가 아닌 경우 예외를 발생시킨다.
  - 로또는 6개를 입력해야합니다.
- 입력한 로또 번호 중 1~45 사이가 아닌게 존재하는 경우 예외를 발생시킨다.
  - 로또 번호는 1~45 사이여야합니다.

### 6. 보너스 볼 번호를 입력받는다
- 시스템 입력을 통해 보너스 볼 번호를 1개를 입력받는다.
  - 입력 : 보너스 볼을 입력해 주세요.
- 입력한 번호가 1개가 아닌 경우 예외를 발생시킨다.
  - 보너스 볼은 1개만 입력할 수 있습니다.
- 보너스 볼 번호가 1~45 사이가 아닌 경우 예외를 발생시킨다.
  - 로또 번호는 1~45 사이여야합니다.
- 보너스 볼이 당첨 로또번호와 중복될 경우 예외를 발생시킨다.
  - 보너스 볼은 당첨 번호에 포함되면 안됩니다.

### 7. 당첨통계를 낸다
- 아래 기준에 따라 당첨결과를 출력한다
  - 3개 일치 : 5,000원
  - 4개 일치 : 50,000원
  - 5개 일치 : 1,500,000원
  - 5개 일치,보너스볼 일치 : 30,000,000원
  - 6개 일치 : 2,000,000,000원
- 수익률을 계산하여 출력한다 
  - 수익률(%) : 총 당첨금 / 구입금액
  - 소수점 둘째 자리까지 출력한다

## 프로그래밍 요구 사항
- 모든 원시값과 문자열을 포장한다.
- 예외 처리를 통해 에러가 발생하지 않도록 한다.
- 모든 기능을 TDD로 구현해 단위 테스트가 존재해야 한다. 단, UI(System.out, System.in) 로직은 제외
  - 핵심 로직을 구현하는 코드와 UI를 담당하는 로직을 구분한다.
  - UI 로직을 InputView, ResultView와 같은 클래스를 추가해 분리한다.
- indent(인덴트, 들여쓰기) depth를 2를 넘지 않도록 구현한다. 1까지만 허용한다.
    - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
  - 힌트: indent(인덴트, 들여쓰기) depth를 줄이는 좋은 방법은 함수(또는 메서드)를 분리하면 된다.
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현한다.

- 배열 대신 컬렉션을 사용한다.

## 학습한 것
- 🔥 companion object란?
 - 클래스 내부에 딱 1개만 둘 수 있는 특별한 object
 - 이 안에 선언된 멤버는 클래스명으로 바로 접근 가능
 - Java에서 말하는 static 멤버처럼 동작하지만, 사실은 companion object 내부의 함수와 변수는 클래스 로딩 시 생성되는 싱글톤 객체
- 🔥is 는 타입체크 연산자이다.
  - 메서드명이 is 로 되어있으면 이스케이프(`) 해줘야한다.
- 🔥객체 생성 시 인자에 대한 유효성 검사를 하고 싶은 경우 다음과 같은 방법을 이용할 수 있다.
  - 주 생성자에 대한 검증은 init 블록으로 처리
  - 보조 생성자에 대한 검증은 constructor 블록 내에서 처리
  - 검증 방법
    - require -> 입력값에 대한 검증. 실패 시 IllegalArgumentException 발생
    - check -> 객체 상태에 대한 검증. 실패 시 IllegalStateException 발생
    - error -> 무조건 예외를 발생시킴. 주로 도달할 수 없는 코드에 사용
    - assert -> 디버깅 목적으로 사용. JVM 옵션 -ea(Enable Assertions)가 활성화된 경우에만 동작
  - List를 생성자로 받을 수 있다.
